# CakeOZ

A full-stack cake ordering application with React frontend and Node.js backend.

## Project Structure

```
cakeoz/
├── frontend/          # React + TypeScript + Vite frontend
├── backend/           # Node.js + Express backend
└── README.md          # This file
```

## Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm start
```

## Features

- Customer cake ordering system
- Custom cake inquiry forms
- User authentication and sign-in
- Responsive design with Tailwind CSS
- Modern UI with shadcn/ui components
